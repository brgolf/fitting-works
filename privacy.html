1. 상담 메모 입력과 저장

입력 항목은 성함, 관심 프로그램, 선택 입력한 고민 내용입니다. 입력 내용은 브라우저에서 상담 메모 파일을 만드는 데만 사용하며 매장 서버에 전송하거나 저장하지 않습니다. 입력 중인 내용은 페이지를 닫거나 새로고침하면 유지되지 않습니다. 다운로드한 파일은 이용자의 기기에 남으며 직접 삭제할 수 있습니다.

2. 접속 정보와 호스팅

본 사이트는 GitHub Pages로 제공됩니다. GitHub는 보안 목적으로 방문자의 IP 주소를 기록·저장한다고 안내하고 있습니다. 해당 접속 정보의 처리와 보관은 GitHub 정책을 확인해 주세요. 운영자가 별도의 분석 도구나 광고 추적기를 설치하지 않았으며, 사이트 코드에서 쿠키나 로컬 저장소로 상담 내용을 보관하지 않습니다.

3. 외부 지도와 링크

4. 정보 제공·위탁 및 이용자 문의

상담 메모의 입력 내용을 제3자에게 제공하거나 처리 위탁하지 않습니다. 호스팅 및 외부 지도 서비스의 정보 처리는 위 항목을 확인해 주세요. 홈페이지에 입력한 내용에 대한 열람·정정·삭제 문의는 아래 연락처로 요청할 수 있습니다. 운영자가 수신·보관하지 않은 입력 내용은 이용자 기기에서 직접 수정·삭제해야 합니다.
